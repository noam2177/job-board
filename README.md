# מעקב משרות

עמוד אחד מתוך קובץ משרות מקומי. העמוד לא שולח מייל ולא פותח דפדפן.

הדוגמה ב-`fixtures/jobs.json` מומצאת. אין כאן חברות אמיתיות ואין קורות חיים.

## איך זה עובד

1. כל משרה היא רשומה: חברה, תפקיד, מיקום, סוג פנייה, סטטוס, וכתובת.
2. הסטטוסים הקבועים הם: לא הוגש, מייל נשלח, טופס הוגש, נסגר.
3. כל כתובת נכנסת לטבלת מקורות פעם אחת, גם אם שתי משרות מצביעות עליה.
4. `render` בונה HTML. תווים כמו `<` נשמרים כטקסט, לא כתגית.
5. `python board.py` כותב את `board.html` ליד הסקריפט.

```text
python -m unittest discover -s tests -q
python board.py
```

אחר כך לפתוח את `board.html` בדפדפן.
